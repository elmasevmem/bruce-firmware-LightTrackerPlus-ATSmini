# Bruce App Store submissions

Ready-to-copy entries for https://github.com/BruceDevices/App-Store-Data.

Copy each app folder to:

    repositories/elmasevmem/bruce-firmware-LightTrackerPlus-ATSmini/<App Name>/

in a fork of App-Store-Data and open a pull request.

To publish an update: change the script, push, then bump `version` and set `commit`
to the new full commit hash in `metadata.json`.
